# RUUNA Programming Language

**RUUNA** — экспериментальный язык программирования, который стремится создать комфортную среду разработки без громоздких зависимостей и сложной предварительной настройки (zero-setup).

Синтаксис языка объединяет идеи **Kotlin** (строгая типизация, безопасность нулевых ссылок, `val`/`var`, `fun`), **C++** (блоки с фигурными скобками `{ }`) и **Lua** (интуитивность и простота восприятия).

## Ключевые особенности

- **Zero-setup:** один компактный исполняемый файл утилиты сборки — и можно писать код, без тяжелых сред выполнения и сложной конфигурации.
- **Гибридный синтаксис:** фигурные скобки, типы после двоеточия (`name: String`) и современные языковые конструкции.
- **Гибкая система сборки (`ruumake`):** выбор целевой платформы и формата выполнения одной командой.

## Пример кода на RUUNA

```ruuna
val maxRetries: Int = 3
var currentAttempt: Int = 0
val username = "CyberKnight"
val greeting = "Hello, " .. username .. "!"
val answer = 3 + 2 * 4
val answerText = "Answer: " .. tostring(answer)
var active: Bool = true

currentAttempt = answer / 2
print(greeting)
print(currentAttempt)
print(answerText)
print(active)
```

## Утилита сборки (`ruumake`)

RUUNA использует флаг `-rumt` (ruuna make type) для выбора режима компиляции.

### Сборка bootstrap-компилятора

Первый прототип `ruumake` написан на C++ и разделён на модули в каталоге `Source/`. Для сборки нужны `make` и C++17-компилятор:

```sh
make
```

Команда создаст исполняемый файл `ruumake` в текущей папке. В Linux программу из текущей папки запускают с префиксом `./`, например `./ruumake --help`. Для удаления собранного файла выполните `make clean`. Для сборки исходной программы `ruumake` затем использует системный C-компилятор `cc`.

Чтобы собрать компилятор для Windows из Linux, установите MinGW-w64 и выполните:

```sh
make exe
```

Цель создаёт `ruumake.exe` с помощью `x86_64-w64-mingw32-g++`. Если кросс-компилятор установлен под другим именем или сборка выполняется из Windows с MinGW, его можно указать явно, например `make exe WIN_CXX=g++`. На Windows собранный `ruumake.exe` требует доступный в `PATH` компилятор MinGW `gcc`, который он использует для сборки RUUNA-программ.

Bootstrap-компилятор поддерживает переменные `val` и `var` типов `Int`, `String` и `Bool`. Тип можно указать явно (`val count: Int = 3`) или вывести из начального значения (`val name = "RUUNA"`). `val` нельзя переназначить, `var` можно; повторные объявления и присваивания значений другого типа приводят к ошибке компиляции. Для `Int` доступны унарные `+`/`-`, сложение, вычитание, умножение, деление и остаток от деления (`%`); умножение и деление имеют приоритет выше сложения и вычитания, а скобки задают порядок вычислений. Деление на ноль диагностируется во время выполнения. `tostring(...)` преобразует значение `Int` в `String`, например `"Answer: " .. tostring(3 + 2)`. Строки можно объединять через `..`. `print(...)` выводит строку, число или `true`/`false` и перевод строки. Строковые литералы поддерживают экранирование `\n`, `\r`, `\t`, `\\` и `\"`; комментарии начинаются с `//` или `--`. Функции, классы, nullable-типы и оператор `or` пока не реализованы.

Создайте файл `hello.rn`:

```sh
cat > hello.rn <<'EOF'
val name = "RUUNA"
var visits: Int = 1
val total = 3 + 2 * 4
print("Hello, " .. name .. "! Total: " .. tostring(total))
print(visits)
visits = 2
print(visits)
EOF
```

### Нативный режим (`native`)

Компилирует исходный файл в нативный исполняемый файл средствами системного C-компилятора:

```sh
./ruumake -rumt:native hello.rn -o hello
./hello
```

В Linux у исполняемого файла обычно нет расширения `.exe`. Компилятор создаёт файл `hello` с правом на запуск, а `./hello` запускает его из текущей папки. Для запуска по имени без `./` файл должен находиться в каталоге из переменной `PATH`.

На текущем этапе поддерживается POSIX-среда с установленным C-компилятором `cc`.

### Режим виртуальной машины (`vm`, планируется)

В будущем этот режим будет упаковывать код в архив байт-кода `.rsa` (Ruuna Source/Bytecode Archive) для выполнения в RUUNOVM:

```sh
ruumake -rumt:vm main.rn -o source.rsa
```
